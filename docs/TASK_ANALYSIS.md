# 과제 분석 문서

## 1. 과제 개요

- **회사**: (주)제이지그룹
- **포지션**: AI PM
- **트랙**: Track 2 - 마케팅 AI 에이전트 개발
- **미션**: 유튜브 연애 영상에 맥락 맞는 댓글을 달아, 시청자가 '운명원'에서 연애 사주를 보고 싶어지도록 유도
- **제출물**: 시연 영상 (필수) + Git 저장소 (선택) + 제작 의도
- **상금**: 최종 선발 시 20만원

## 2. 필수 요구사항

### 패널 1: 영상 불러오기
- [영상 불러오기] 버튼 클릭 시 최신 영상 목록 로드
- 표시 정보: 썸네일, 제목, 채널명, 업로드 날짜

### 패널 2: 영상 선택
- 목록에서 영상 선택 시:
  - AI가 자막(없으면 제목·설명)과 인기 댓글 분석
  - 영상 속 연애 고민 한 줄 요약
  - 댓글 초안 생성

### 댓글 작성 규칙
- 40~120자
- 영상 속 구체적 장면/말 1개 이상 언급
- 영상마다 다른 댓글
- 시청자 페르소나로 자연스럽게
- '운명원' 연애 사주를 보고 싶어지도록 유도
- **금지**: 링크, 해시태그, 운명원 이용 후기 조작

### 패널 3: 댓글 달기
- 크롬 프로필(유튜브1) 자동 오픈
- 댓글 창 열기 → 한 글자씩 타이핑 → 게시 → 확인
- 진행 상태 표시: 프로필 여는 중 → 입력 중 → 게시 완료 → 댓글 보기
- 실패 시 이유와 화면 캡처
- 유튜브 한국어 화면에서 작동

### 운영 규칙 (코드에서 강제)
- 영상당 댓글 1개
- 하루 게시 상한: 기본 10개
- 기록: 영상·프로필·댓글 내용·성공/실패 시간순 저장

## 3. 가점 요소

| 가점 항목 | 설명 | 구현 난이도 |
|-----------|------|------------|
| 프로필 3개 배정 | 유튜브1~3 중 선택 또는 자동 배정 | 중 |
| 링크 직접 입력 | 목록 없이 URL로 영상 지정 | 하 |
| AI 키로 즉석 생성 | 새 영상에 대해 즉시 초안 생성 | 중 |
| 뜨기 직전 영상 찾기 | 조회수 1,000~5,000, 시간당 150+ | 상 |

## 5. 기술 설계

### 아키텍처

```
[React Frontend] ←→ [Express Backend]
                        ├── YouTube Data API v3 (영상 검색/자막)
                        ├── Claude API (댓글 생성)
                        ├── Playwright (크롬 프로필 자동화)
                        └── SQLite (기록 저장)
```

### YouTube API 활용
- `search.list`: 연애 키워드로 최신 영상 검색
- `videos.list`: 영상 상세 정보 (조회수, 설명 등)
- `captions.list` + `captions.download`: 자막 가져오기
- `commentThreads.list`: 인기 댓글 가져오기

### AI 댓글 생성 흐름
1. 영상 자막/제목/설명 + 인기 댓글 수집
2. Claude에게 영상 맥락 분석 요청 → 연애 고민 한 줄 요약
3. 시청자 페르소나로 운명원 유도 댓글 초안 생성
4. 40~120자 제약 확인

### Playwright 자동화 흐름
1. `launchPersistentContext`로 크롬 프로필 열기
2. 유튜브 영상 페이지 이동
3. 댓글 입력란 클릭
4. 한 글자씩 타이핑 (사람처럼)
5. 게시 버튼 클릭
6. 댓글 게시 확인
7. 상태 실시간 전송 (WebSocket)

### 설정 예시
```yaml
profiles: [유튜브1, 유튜브2, 유튜브3]
comment:
  min_chars: 40
  max_chars: 120
  brand: 운명원
limits:
  daily_max_comments: 10
```
